# NASA 3D model mirror for Planetarium

A copy of models and thumbnails from [nasa/NASA-3D-Resources](https://github.com/nasa/NASA-3D-Resources),
served through Cloudflare Pages so that app users do not all download from GitHub.
Paths are unchanged from the NASA repository.
